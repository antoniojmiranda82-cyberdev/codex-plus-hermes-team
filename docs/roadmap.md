# Roadmap

## MVP

- MCP server over stdio.
- Hermes profile discovery.
- Configurable agent registry.
- Role/capability routing.
- Basic Russian/English routing aliases.
- Route confidence, `why`, and selected score details.
- One-shot specialist calls.
- Role discovery via `hermes_team_discover_roles`.
- Panel calls with structured synthesis buckets.
- Optional Hermes Kanban task creation, status reading, and result collection.
- Side-effect policy with `advice_only` default.
- `init-config` and `doctor` install checks.

## Next

- Cached capability discovery.
- Streaming panel responses.
- Workspace allow/deny policy.
- Codex and Claude Code install helpers.
- Test matrix for macOS, Linux, WSL, and devcontainers.

## Later

- Remote Hermes provider.
- Dashboard.
- GitHub issue/PR workflows.
- Team templates for coding, content, research, operations, and product.
- Marketplace packaging.
